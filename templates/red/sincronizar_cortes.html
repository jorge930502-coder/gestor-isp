El sistema revisa quién debe (factura vencida con el día de corte cumplido, o cliente ya suspendido) y actualiza la address-list de morosos en el router: corta a los que deben y reconecta a los que ya pagaron.

{% csrf_token %}

Requisitos en el Mikrotik (una vez):

/ip firewall address-list add list=MOROSOS address=0.0.0.0 disabled=yes comment="placeholder"
/ip firewall filter add chain=forward src-address-list=MOROSOS action=drop comment="Corte morosos"
/ip firewall filter add chain=forward dst-address-list=MOROSOS action=drop

El usuario de la API debe tener permiso de escritura (grupo write o full).
